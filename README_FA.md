# Javdan Price Labeler — Android V2

این پروژه نسخه اندروید نرم‌افزار **Javdan Price Labeler** است.

## قابلیت‌ها
- دو حالت مستقل: **Excel** و **ورود دستی**
- در حالت دستی:
  - انتخاب عکس از Gallery / Files
  - قیمت مصرف‌کننده
  - قیمت پایه
  - قیمت شماره ۱
  - قیمت شماره ۲
  - تغییر نام هر قیمت به نام دلخواه
  - افزودن یا حذف تعداد نامحدود ردیف قیمت
  - تبدیل اختیاری ریال به تومان
- در حالت Excel:
  - انتخاب فایل XLSX از گوشی
  - انتخاب پوشه تصاویر
  - انتخاب ستون کد محصول
  - تطبیق نام عکس با کد Excel
  - خواندن ستون‌های قیمت
  - ساخت گروهی خروجی
- طراح Drag & Drop:
  - جابه‌جایی هر فیلد با انگشت
  - تغییر نام فیلد
  - تغییر مقدار
  - خط‌خورده کردن قیمت
  - افزودن و حذف فیلد
  - ذخیره قالب
- خروجی:
  - پیش‌نمایش
  - ذخیره JPG در `Pictures/JavdanPriceLabeler`
  - خروجی گروهی Excel
- امنیت:
  - هیچ مجوز Internet در Manifest وجود ندارد
  - هیچ آپلود یا Telemetry وجود ندارد
  - فایل‌ها با Android Storage Access Framework انتخاب می‌شوند
  - عکس اصلی بازنویسی نمی‌شود

## ساخت APK
این محیط فعلی Android SDK ندارد، بنابراین APK کامپایل‌شده داخل این بسته نیست.

در Android Studio:
1. پوشه پروژه را Open کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. از منوی **Build > Build APK(s)** استفاده کنید.
4. خروجی در مسیر زیر ساخته می‌شود:
   `app/build/outputs/apk/debug/app-debug.apk`
5. می‌توانید نام آن را به `JavdanPriceLabeler.apk` تغییر دهید.

## تکنولوژی
پروژه عمداً بدون کتابخانه خارجی Excel نوشته شده است. فایل XLSX به شکل محلی و Read-only از ساختار ZIP/XML خوانده می‌شود تا برنامه سبک‌تر و آفلاین بماند.

## نکته Excel
در نسخه فعلی Android، Sheet اول XLSX خوانده می‌شود. ردیف اول باید Header باشد و بهتر است ستون اول یا ستون انتخابی کد محصول باشد.
