# Javdan Price Labeler v3.6 — Camera Input

بر پایه v3.5 Smart Snap.

## قابلیت جدید
- در حالت ورود دستی، دکمه «افزودن عکس محصول» یک انتخاب‌گر باز می‌کند:
  - انتخاب از گالری / Files
  - گرفتن عکس با دوربین
- عکس دوربین با `MediaStore.ACTION_IMAGE_CAPTURE` و `EXTRA_OUTPUT` در رزولوشن کامل ذخیره می‌شود.
- عکس دوربین وارد همان مسیر پردازش محصول می‌شود: Smart Snap، Crop، Resize، Preview و Export.
- جهت EXIF برای عکس‌های دوربین/گالری اصلاح می‌شود.
- در صفحه Designer نیز دکمه «انتخاب / تغییر عکس نمونه» همین انتخاب‌گر گالری/دوربین را باز می‌کند.
- در صورت لغو دوربین، فایل رزروشده پاک می‌شود.

## فایل جایگزین
`MainActivity.java`

`LabelDesignerView.java` همان نسخه v3.5 است و برای راحتی همراه بسته قرار گرفته است.

## Build
`gradle :app:assembleDebug --stacktrace`

## نکته مجوز
این نسخه دوربین را با Intent برنامه دوربین سیستم فراخوانی می‌کند؛ بنابراین برای خود اپ نیازی به درخواست مستقیم مجوز CAMERA ندارد.
